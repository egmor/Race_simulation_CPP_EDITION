# Laptime Calculator

Консольная программа на C++, рассчитывающая примерное время прохождения круга гоночной трассы. Трасса задана как последовательность прямых и поворотов; в коде используются данные, соответствующие автодрому **Monza** (Rettifilo, Curva Grande, Lesmo, Variante Ascari, Parabolica).

## Как это работает

Трасса представлена вектором сегментов `Segment`. Каждый сегмент — это либо прямая, либо поворот.

### Структура `Segment`

| Поле | Описание |
|---|---|
| `distance` | Длина участка, м |
| `degree` | Угол поворота, ° (0 для прямых) |
| `height_difference` | Перепад высот на участке, м |
| `is_straight` | Флаг: `true` — прямая, `false` — поворот |

Есть два конструктора:
- `Segment(distance)` — создаёт прямую;
- `Segment(distance, degree, height_difference)` — создаёт поворот.

### Расчёт времени сегмента — `calculate_segment_time`

**Прямая:** время = длина / средняя скорость на прямой (константа `58.0` м/с).

**Поворот:**
1. Радиус поворота оценивается по длине хорды и углу дуги:
   `R = distance / (2 * sin(degree_в_радианах))`
2. Учитывается продольный уклон участка через `asin(|height_difference| / distance)`.
3. Максимальная скорость в повороте находится из баланса сил сцепления шин и веса:
   `v_max = sqrt(grip * g * R * cos(slope))`, где `grip = 1.6`, `g = 9.81`.
4. Время = длина / `v_max`.

### `main`

Собирает трассу из 18 сегментов (прямые + повороты Monza), суммирует время всех сегментов и выводит результат в формате `минуты:секунды.миллисекунды`.

## Сборка и запуск

```bash
g++ -O2 -std=c++17 laptime_calculating.cpp -o laptime
./laptime
```

## Пример вывода

```
Общее время прохождения трека: 1:21.734
```//time is illustrative, конкретное значение зависит от параметров модели

## Ограничения модели

- Радиус поворота, вычисленный по хорде, — приближение; для реальной трассы точнее использовать данные о радиусе дуги напрямую.
- Не учитываются торможение/разгон на входе и выходе из поворотов (мгновенный переход между скоростями).
- Коэффициент сцепления `tyre_grip = 1.6` и средняя скорость на прямой `58.0` м/с — фиксированные константы, не зависящие от конкретного автомобиля.
- Знак `height_difference` не влияет на результат — используется `std::abs`.
