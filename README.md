# Laptime Calculator

Консольная программа на C++, рассчитывающая примерное время прохождения круга гоночной трассы **Monza** (Rettifilo, Curva Grande, Lesmo, Variante Ascari, Parabolica). В отличие от простой покилометровой оценки, эта версия моделирует разгон и торможение автомобиля между поворотами.

## Как это работает

Трасса представлена вектором `Corner` — единой структурой и для прямых, и для поворотов (прямая — это поворот с `degree = 0`).

### Структура `Corner`

| Поле | Описание |
|---|---|
| `distance` | Длина участка, м |
| `degree` | Угол поворота, ° (0 — прямая) |
| `height_difference` | Перепад высот на участке, м |

Конструктор `Corner(distance, degree = 0.0, height_difference = 0.0)` позволяет создавать и прямые (`Corner(1120.0)`), и повороты (`Corner(320.0, 35.0, -2.5)`) единым способом.

### `get_max_corner_speed` — максимальная скорость в повороте

Для прямых (`degree ≈ 0`) сразу возвращает топ-спид (`95.0` м/с). Для поворота:
1. Радиус поворота оценивается как `distance / angle_rad` (длина дуги, делённая на угол в радианах).
2. Уклон участка учитывается через `asin(|height_difference| / distance)`.
3. Максимальная скорость по сцеплению: `v_max = sqrt(grip * g * R * cos(slope))`, где `grip = 1.6`, `g = 9.81`.

### `calculate_segment_time` — время прохождения сегмента

Функция принимает текущий сегмент, указатель на **следующий** сегмент и скорость входа `speed_enter` (передаётся по ссылке и обновляется — так скорость "переносится" от участка к участку по всему кругу).

**Прямая:**
- Целевая скорость на выходе с прямой — это максимальная безопасная скорость **следующего** поворота (`get_max_corner_speed(*next_seg, ...)`), либо топ-спид, если следующего сегмента нет.
- Считается тормозной путь, необходимый, чтобы снизить скорость до целевой: `S_brake = (V² − V_target²) / (2·a_decel)`, где `a_decel = tyre_grip * g`.
- Если тормозного пути не хватает на всю прямую — участок делится на фазу разгона (`accel = 5.0` м/с²) и фазу торможения; время считается как среднее время на каждой фазе (по средней скорости).
- Если прямая короче тормозного пути — участок целиком проходится в режиме торможения (скорость на выходе не опускается ниже целевой скорости поворота).

**Поворот:**
- Считается максимально допустимая скорость входа в поворот (`get_max_corner_speed`).
- Если фактическая скорость входа превышает её более чем на 2% — выводится предупреждение `[ВНИМАНИЕ] Вылет с трассы в повороте!`, скорость принудительно ограничивается максимальной.
- Скорость на выходе принимается равной допустимой (без разгона в повороте), время — `distance / средняя_скорость`.

### `main`

Собирает 18 сегментов трассы Monza, стартует со скоростью `80.0` м/с и последовательно проходит их по кругу. Список **закольцован**: у последнего сегмента "следующим" считается первый (`(i + 1) % size`), поэтому расчёт торможения перед финишной прямой учитывает первый поворот нового круга.

В конце время переводится в миллисекунды и выводится в формате `минуты:секунды.миллисекунды`, а также в секундах.

## Сборка и запуск

```bash
g++ -O2 -std=c++17 laptime_calculating.cpp -o laptime
./laptime
```

## Пример вывода

```
Результат без вылетов: 1:26.412 (86.412 с)
```
Точное значение зависит от параметров модели; при неверно заданных углах/скорости возможны предупреждения о вылете.

## Ограничения модели

- Радиус поворота (`distance / angle_rad`) — приближение по длине дуги, не по хорде; точность зависит от того, как измерено `distance`.
- Разгон/торможение считаются с постоянным ускорением (`5.0` и `tyre_grip * g` м/с² соответственно) — не учитывается зависимость тяги от скорости, аэродинамика и т.п.
- В повороте скорость считается постоянной (без разгона на выходе из поворота).
- `tyre_grip = 1.6`, `max_straight_speed = 90.0` м/с (в `calculate_segment_time`) и `95.0` м/с (топ-спид в `get_max_corner_speed`) — разные константы для похожих величин; при желании их стоит унифицировать.
- Проверка на "вылет" лишь выводит предупреждение и ограничивает скорость — не прерывает расчёт и не штрафует итоговое время.
