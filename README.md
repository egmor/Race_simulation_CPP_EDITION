# Laptime Calculator

Консольная программа на C++, рассчитывающая время прохождения трассы **Monza** (Rettifilo, Curva Grande, Lesmo, Variante Ascari, Parabolica) с физической моделью автомобиля: тяга двигателя, сопротивление воздуха, сцепление шин, а также деградация шин и расход топлива за гонку из 50 кругов.

## Как это работает

### Глобальные константы — `gc`

`g` (9.81 м/с²), `pi`, `air_density` (1.225 кг/м³) — вынесены в отдельное пространство имён.

### Структура `Car`

| Поле | Описание |
|---|---|
| `horsepower` | Мощность двигателя, л.с. (по умолчанию 530) |
| `weight` | Масса автомобиля, кг (по умолчанию 1320) |
| `Cd_A` | Коэффициент аэродинамического сопротивления × площадь (`C_d * A`) |
| `tyre_grip` | Коэффициент сцепления шин (по умолчанию 1.28) |
| `effective_hp` | Мощность с поправкой на КПД трансмиссии (`horsepower * 0.88 * 0.91`) |

`get_hp_to_watts()` переводит эффективную мощность в ватты.

`weight` и `tyre_grip` не константы — они меняются по ходу гонки (см. `main`), поэтому один и тот же автомобиль "устаёт" от круга к кругу.

### Структура `Corner`

Как и раньше: `distance`, `degree` (0 — прямая), `height_difference`. Конструктор с параметрами по умолчанию покрывает и прямые, и повороты.

### `get_max_corner_speed(seg, tyre_grip)`

Для прямых возвращает `100.0` м/с (360 км/ч). Для поворота:
1. Радиус: `distance / angle_rad`.
2. Уклон: `asin(|height_difference| / distance)`.
3. Скорость по сцеплению: `sqrt(tyre_grip * g * R * cos(slope))`.
4. **Штраф на медленных шиканах**: если угол поворота больше `75°`, скорость дополнительно умножается на `0.82` — модель того, что в очень острых поворотах реальная проходная скорость ниже, чем даёт чистая формула сцепления.

### `get_current_accelerate(car, speed)` — ускорение автомобиля

Учитывает три силы:
- **Тяга двигателя**: `P / v` (сила падает с ростом скорости при постоянной мощности);
- **Предел по сцеплению**: `tyre_grip * weight * g` — тяга не может превышать её (иначе пробуксовка);
- **Сопротивление воздуха**: `0.5 * air_density * Cd_A * v²`.

Итоговое ускорение = `(min(тяга_двигателя, тяга_по_сцеплению) − сопротивление_воздуха) / weight`.

### Торможение: два варианта

- `get_safe_decel_forces(car)` — замедление **только по сцеплению шин**, без аэродинамики. Используется для консервативной оценки тормозного пути (чтобы не тормозить "слишком поздно" в расчёте).
- `get_decel_forces(car, v)` — реальное замедление с учётом и сцепления, и аэродинамического сопротивления (в реальности воздух тоже помогает тормозить). Используется в самой симуляции торможения.

### `get_target_speed_ahead(track, current_idx, car)` — взгляд вперёд

Ищет минимально допустимую скорость среди **следующих 3 сегментов** трассы (или пока накопленная дистанция не превысит 300 м) — чтобы при подготовке к связке поворотов (например, шикана из двух поворотов подряд) автомобиль тормозил под самый медленный из них, а не только под ближайший.

### `calculate_segment_time(track, current_idx, car, speed_enter)` — время сегмента

Скорость `speed_enter` передаётся по ссылке через всю трассу и все круги — состояние автомобиля никогда не сбрасывается.

**Прямая — численное интегрирование с шагом `dt = 0.005` с:**
1. Определяется целевая скорость впереди (`get_target_speed_ahead`).
2. На каждом шаге вычисляется безопасный тормозной путь (`get_safe_decel_forces`) до целевой скорости.
3. Если оставшейся дистанции хватает только на торможение — применяется реальное замедление (`get_decel_forces`, с аэродинамикой); иначе — ускорение (`get_current_accelerate`).
4. Скорость и пройденная дистанция обновляются на каждом шаге (`v += a*dt`, `s -= v*dt`), с ограничением сверху по максимальной скорости коробки передач (`285 км/ч`).
5. Итоговое время сегмента — сумма всех шагов `dt`.

**Поворот:**
1. Считается максимально допустимая скорость входа. Если фактическая скорость превышает её больше чем на 1% — предупреждение `[ВНИМАНИЕ] Вылет с трассы в повороте!`, скорость принудительно ограничивается.
2. Дополнительно учитывается **следующий** поворот: скорость на выходе — это минимум из (текущей скорости, лимита текущего поворота, лимита следующего поворота). Так связки поворотов (T1→T2, T4→T5 и т.д.) проходятся с оглядкой на второй апекс.
3. Время = `distance / средняя_скорость`.

### `main` — симуляция 50 кругов

1. Создаётся автомобиль `Car car;` со значениями по умолчанию и трасса из 18 сегментов Monza.
2. Стартовая скорость — `80.0` м/с.
3. Внешний цикл — `50` кругов, внутренний — все сегменты трассы; скорость и время переносятся между кругами без сброса.
4. **После каждого круга:**
   - `car.tyre_grip -= 0.0005` — износ резины снижает сцепление;
   - `car.weight -= 2.75` — сгоревшее топливо снижает массу.
   
   Из-за этого более поздние круги быстрее проходят повороты (машина легче), но чуть хуже держат сцепление (изношенная резина) — эти эффекты действуют в противоположные стороны.
5. В конце суммарное время всех 50 кругов переводится в `минуты:секунды.миллисекунды` и выводится вместе с точным значением в секундах.

## Сборка и запуск

```bash
g++ -O2 -std=c++17 laptime_calculating.cpp -o laptime
./laptime
```

## Пример вывода

```
Результат без вылетов: 71:24.180 (4284.180 с)
```
Это суммарное время **за 50 кругов**, а не за один круг. Точное значение зависит от параметров модели.

## Ограничения модели

- Радиус поворота (`distance / angle_rad`) — приближение по длине дуги, не по хорде.
- Штраф `× 0.82` для поворотов острее 75° — эмпирическая константа, не выведена из физики.
- Аэродинамическая прижимная сила (downforce) не моделируется — `tyre_grip` считается постоянным по величине сцепления независимо от скорости, хотя в реальности прижимная сила растёт с квадратом скорости и увеличивает предельное сцепление.
- В повороте скорость по-прежнему считается постоянной (без разгона внутри самого поворота) — динамика есть только на прямых.
- Численное интегрирование с фиксированным шагом `dt = 0.005` с — точность зависит от шага; при очень коротких прямых или резких переходах возможны небольшие погрешности.
- Деградация резины (`-0.0005` за круг) и расход топлива (`-2.75` кг за круг) — линейные и не связаны с реальной физикой износа или расхода топлива конкретного двигателя.
- Проверка на "вылет" лишь выводит предупреждение и ограничивает скорость — не прерывает расчёт и не штрафует итоговое время.
